# Sports Scores

Live scores and game tracking across 17 leagues, ranked so the games that matter surface first.

**Live demo:** https://123125sportsscores.vercel.app

## What it does

- Fetches scores from 17 leagues at once with parallel API calls
- Ranks games by importance: playoff status, broadcast, team quality, and context
- Caps games per league so no single sport takes over the feed
- Shows today's games, or falls back to yesterday when nothing's on

## Built with

React, Vite, Tailwind
